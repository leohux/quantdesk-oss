# Changelog

All notable changes to QuantDesk will be documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses semantic versioning.

## [Unreleased]

### Added

- Community issue and pull-request templates.
- Product screenshot gallery.
- Contributor Covenant.

## [0.1.2] - 2026-08-20

### Added

- One-click Windows launchers (`打开QuantDesk.bat` / `关闭QuantDesk.bat`) and `start.sh` so unzipped users can start Docker without typing commands.

## [0.1.0] - 2026-07-29

### Added

- Event-driven strategy, risk, execution, and OMS core.
- Shared strategy interface across backtest, paper, and live runners.
- Alpaca paper execution and fail-closed IBKR live path.
- FastAPI backend and React dashboard.
- Docker Compose deployment, bilingual documentation, CI, and security guidance.
